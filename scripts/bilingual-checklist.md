## 📝 Sub-Agent Prompt Template

```
Translate the file at [EN_SOURCE] to English.

Create an English version that:
- Translates all headers and body text to English
- Keeps the same structure (sections, tables, lists)
- Keeps technical terms as-is (SDD, HU, ADR, RFC, Given/When/Then, etc.)
- Updates Spanish placeholders to English equivalents where appropriate
- Maintains any @author references as @author

Save English version to [EN_DESTINATION] (replace existing).
Save Spanish version to [ES_DESTINATION] with original Spanish content.

Return brief summary of what was done.
```

## ✅ Validation After Each Batch

After completing each phase, verify:

1. **EN file exists** and is in English
2. **ES file exists** and is in Spanish (original content)
3. **Links work** — internal references still point to correct paths
4. **No mixed languages** — EN file should be fully in English
