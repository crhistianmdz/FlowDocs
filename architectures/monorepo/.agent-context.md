# Context - Monorepo

> ⚠️ Reglas compartidas (testing, branches, commits, tech-debt, DoD) en `AGENTS.md` en la raíz del proyecto.

**Tipo de Arquitectura**: Monorepo (múltiples paquetes en un repo)

---

## Descripción

Proyecto con múltiples paquetes/bibliotecas que comparten código. Ejemplos:
- Angular workspace con múltiples libs
- Node.js con workspaces
- Rust con workspaces
- Turborepo

---

## Características

| Característica | Valor |
|----------------|-------|
| Paquetes | Múltiples en `packages/` |
| Shared code | Packages comunes en `shared/` |
| Builds | Por paquete o total |
| Testing | Por paquete |

---

## Estructura de Docs

```
docs/
├── PRD.md
├── RFC.md
├── shared/              ← Paquetes compartidos
│   ├── ui-components/
│   ├── utils/
│   └── types/
├── packages/
│   ├── web-app/
│   │   ├── api/
│   │   ├── components/
│   │   └── tasks/
│   └── mobile-app/
│       ├── screens/
│       └── tasks/
└── tools/
    └── scripts/
```

---

## Configuración SDD

- Módulo específico: usar `--module=nombre-paquete`
- Cambios cross-package: crear HU en `docs/shared/`
- **⚠️ Siempre usar `--from-docs`**: sin ese flag, el agente NO lee la HU

---

## Comandos Típicos

```bash
# Build all
npm run build

# Build specific package
npm run build --workspace=packages/web-app

# Test all
npm test

# Test specific package
npm test --workspace=packages/web-app
```
