## Why gaps in numbering?

Numbers are **never reused**. When an RFC is deprecated, it stays at its number for historical reference.

## Lifetime

RFCs have a **maximum lifetime of 2 weeks**, then either:
- Becomes an ADR (decision made)
- Closes without action (no consensus)

## Creating an RFC

1. Copy `../../templates/architecture/RFC_template.md`
2. Use the next available number
3. Status starts as `Draft` → `In Review` → `Accepted` (or `Closed`)
