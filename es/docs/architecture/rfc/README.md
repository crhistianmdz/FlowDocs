## ¿Por qué hay huecos en la numeración?

Los números **nunca se reutilizan**. Cuando un RFC se deprecó, mantiene su número como referencia histórica.

## Tiempo de vida

Los RFCs tienen un **tiempo máximo de 2 semanas**, luego:
- Se convierte en ADR (se tomó decisión)
- Se cierra sin acción (sin consenso)

---

## Crear un RFC

1. Copiá `../../templates/architecture/RFC_template.md`
2. Usá el siguiente número disponible
3. El estado empieza como `Draft` → `In Review` → `Accepted` (o `Closed`)
