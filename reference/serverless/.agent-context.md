# Context - Serverless

> ⚠️ Reglas compartidas (testing, branches, commits, tech-debt, DoD) en `AGENTS.md` en la raíz del proyecto.

**Tipo de Arquitectura**: Serverless (funciones como servicio)

---

## Descripción

Proyecto basado en funciones serverless desplegadas en la nube. Ejemplos:
- AWS Lambda
- Google Cloud Functions
- Azure Functions
- Vercel/Netlify Functions

---

## Características

| Característica | Valor |
|----------------|-------|
| compute | Funciones individuales |
| Deploy | Cloud provider |
| Escalado | Automático |
| Cold starts | Considerar |

## Comandos Típicos

```bash
# Deploy all
npm run deploy

# Deploy specific function
npm run deploy:auth

# Local invoke
npm run invoke:auth

# Test locally
npm run local
```
